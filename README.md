## 📌 项目简介

本项目旨在通过编写实际的 HTML 页面，掌握网页的基本组成与语法规则。随着学习深入，计划逐步加入 CSS 样式，最终完成一个美观、实用的静态网站。

## 🧠 学习目标

- 学会编写基本的 HTML 页面结构
- 掌握常用 HTML 标签（标题、段落、链接、图片、列表等）
- 理解语义化标签（如 `<header>`、`<article>`、`<footer>`）
- 实践表格、表单等结构的构建
- 初步接触 CSS，实现页面美化（即将开始）
